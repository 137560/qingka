# 轻卡日记

记录**每天吃什么、多少热量、每天步数、消耗多少热量**的个人手机应用（PWA 网页应用）。

- 🍚 点两下完成饮食记录：内置常见食物热量表（米饭/馒头/包子/奶茶/火锅/家常菜等约 160 种），也支持自定义
- ⚖️ 选食物时可调份量（×0.5 / ×1 / ×2 / ×3），记录更贴近实际吃的量
- 🍱 套餐：把常吃的一餐（如 鸡蛋+牛奶+面包）存成套餐，以后一键整餐记录
- ↻ 再吃一次：一键复制上次的早餐/午餐，适合天天吃一样的你
- 📋 每日小结：三餐构成条 + 摄入/步数/喝水/净差一览 + 一句结语，可一键复制分享
- 👣 每天填一次步数（可从微信运动查看），自动换算消耗热量
- 🔥 自动计算基础代谢、目标摄入、热量缺口，显示"照这样每周能减多少"
- 💧 喝水打卡（8 杯目标，1杯=250ml）
- ⚖️ 体重记录 + 30 天趋势曲线 + 目标体重进度条
- 📊 近 7 天净差图（蓝=缺口红=盈余，一眼看懂）、本周小结（与上周对比）、近 12 周热量缺口热力图
- 📱 数据全部存在手机浏览器本地，**不联网、不上传**，可离线使用

## 快速体验（电脑上）

双击 `index.html`，或用浏览器打开它即可。

## 装到手机上（推荐）

手机 Chrome 浏览器打开部署好的网址，点右上角菜单 → **添加到主屏幕 / 安装应用**，之后就像普通 App 一样用，还能离线打开。

### 部署方式 A：GitHub Pages（免费，推荐）

1. 注册 [github.com](https://github.com)，点右上角 **+ → New repository**，仓库名随便起（如 `qingka`），选 **Public**，其余不用动，创建
2. 进入仓库 → **Add file → Upload files** → 把本文件夹里**除 README.md、gen-icons.ps1、skills/、reference/ 外**的所有文件和 `icons` 文件夹一起拖进去 → **Commit changes**
3. 仓库页 → **Settings → Pages** → Source 选 **Deploy from a branch**，Branch 选 **main**、目录选 **/(root)** → **Save**
4. 等一两分钟，访问 `https://你的用户名.github.io/仓库名/`，比如 `https://xiaoming.github.io/qingka/`
5. 手机 Chrome 打开这个网址 → 菜单 → 添加到主屏幕 ✅

### 部署方式 B：Cloudflare Pages / Netlify Drop

- **Cloudflare Pages**：dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets → 把整个文件夹拖进去 → 部署，得到一个网址
- **Netlify**：打开 [netlify.com/drop](https://netlify.com/drop)，把整个文件夹拖进页面，立刻得到一个网址

### 方式 C：不部署（电脑手机同一 WiFi）

电脑上在本文件夹运行 `npx serve .`（或 `python -m http.server 8000`），手机浏览器访问 `http://电脑的IP:8000`。
注意：这种方式**不能"安装"**，但记录功能完全正常。数据存在手机浏览器里，与电脑上的数据互不相通。

## ⚠️ 数据备份很重要

数据存在**浏览器本地**。以下情况会丢数据：

- 清理浏览器缓存/数据
- 换手机、换浏览器
- 换了访问网址（比如从方式 C 换成方式 A）

所以：换之前先在 App 内 **⚙️ 设置 → 导出备份**，拿到 JSON 文件，之后再 **导入备份**。建议每周导出一次。

## 计算说明

- 基础代谢：Mifflin-St Jeor 公式
- 步数消耗：`步数 × 体重 × 0.0005`（约 70kg 的人走 1 万步 ≈ 350 千卡）
- 目标摄入 = 总消耗 − 减重缺口（默认 500，即每周约减 0.45kg）
- **食物热量按「每 100 克」存储**（数值参考《中国食物成分表》熟重常见值），记录时填克数，不用猜「一份」是多少
- 估重小抄（手掌估重法，《中国居民膳食指南》）：一拳主食（熟）≈150g · 一掌心瘦肉≈50g · 鸡蛋1个≈50g · 一捧蔬菜≈100g · 一拇指油≈10g
- 家常菜、外卖等复合菜为常见做法的**估算值**（油盐多少影响很大）；想更准可以用厨房秤称重，或按菜品包装的营养成分表换算

## 升级路线（原生安卓）

以后想升级成自动计步的原生安卓 App 时，用「导出备份 → 导入」就能把记录无缝迁移过去。

## 开发

- 纯 HTML/CSS/JS，无任何依赖，无需构建
- 更新代码后部署时，记得把 `sw.js` 里的 `CACHE` 版本号 +1，手机才会拉到新版本
- 图标重新生成：`powershell -NoProfile -ExecutionPolicy Bypass -File gen-icons.ps1`
